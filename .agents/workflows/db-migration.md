# Workflow: Изменение схемы БД (Alembic)

Если задача требует изменения структуры реляционной БД (PostgreSQL в **Workout Service**):

1. Перейди в директорию сервиса, содержащую `alembic.ini`. Убедись, что переменные окружения (`DATABASE_URL`) заданы корректно.
2. Внеси изменения в SQLAlchemy модели (файлы `models.py`). Для JSONB полей обязательно используй `sqlalchemy.dialects.postgresql.JSONB`.
3. Убедись, что новая модель импортирована в `env.py` (через `target_metadata`) для Alembic.
4. Вызови команду для автогенерации миграции: `alembic revision --autogenerate -m "краткое_описание"`.
5. ВНИМАТЕЛЬНО проверь сгенерированный файл в `alembic/versions/`. Alembic может ошибаться с определением изменений в JSONB, индексах или переименованием колонок.
6. Примени миграцию локально через `alembic upgrade head`.
7. Если миграция падает, откати изменения (`alembic downgrade`), исправь модель/скрипт и повтори.
