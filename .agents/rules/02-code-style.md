# Стандарты кода и типизации

## Технологический стек
- Код должен быть написан на Python 3.12+ с использованием FastAPI (для API) и чистого asyncio (для воркеров).
- Использовать строгую типизацию через Pydantic v2 во всех DTO и схемах.
- Использовать СТРОГО SQLAlchemy 2.0 с паттернами async/await.

## Работа с I/O и асинхронностью
- Любой I/O код (БД, брокеры, Redis, HTTP-запросы) должен быть строго асинхронным. Запрещено использовать блокирующие вызовы.
- Обязательные асинхронные драйверы:
  - PostgreSQL: `asyncpg`
  - MongoDB: `motor`
  - Redis: `redis.asyncio` (запрещено использовать старый aioredis)
  - Kafka: `aiokafka` (или FastStream)
  - RabbitMQ: `aio-pika` (или FastStream, запрещено использовать pika)

## Оформление кода и линтинг
- В начале каждого файла с моделями и схемами обязательно указывать `from __future__ import annotations` (для корректной работы Pydantic v2 и отложенной аннотации типов).
- Код должен быть лаконичным, без избыточных абстракций, если они не требуются бизнес-логикой.
- При модификации существующего кода ИИ-агенту категорически запрещено удалять существующие комментарии разработчика.
- Для проверки качества кода используются:
  - Линтер и форматтер: `ruff` (конфигурация в `.ruff.toml` / `pyproject.toml`).
  - Статический анализатор типов: `mypy` в строгом режиме (`strict = true`).

## Управление зависимостями и структура
- Запрещено использовать единый монолитный `requirements.txt`.
- Каждый микросервис изолирован в собственной директории в корне проекта (`./<service>_service/`, например `./workout_service/`, `./leaderboard_service/`, `./analytics_service/`, `./notification_service/`, а также общие контракты `./shared/contracts/`).
- Внутри каждого микросервиса содержатся:
  - `Dockerfile` (базовый с комментарием-заглушкой);
  - `pyproject.toml` (независимый список зависимостей сервиса);
  - `alembic.ini` и папка `alembic/` (для сервисов с БД);
  - `src/` — строгая слоистая структура:
    - `src/__init__.py`;
    - `src/main.py` (или `src/worker.py` для воркеров);
    - `src/dependencies.py` (зависимости FastAPI: `get_db`, контекст пользователя);
    - `src/core/` (`config.py`, `database.py`, `security.py`, `__init__.py`);
    - `src/models/` (`workout.py`, `outbox.py`, `__init__.py` с реэкспортом);
    - `src/schemas/` (`workout.py`, `__init__.py` с DTO и Discriminated Unions);
    - `src/repositories/` (`base.py` с `BaseRepository`, доменные репозитории, `__init__.py`);
    - `src/controllers/` (бизнес-логика, сервисы, `__init__.py`);
    - `src/routes/` (роутеры FastAPI, `__init__.py` с агрегирующим `router`).
- Запрещено плоское сваливание файлов в корень `src/` без разделения по слоям.
