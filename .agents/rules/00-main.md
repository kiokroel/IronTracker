Перед выполнением любой задачи ты обязан:
1. Прочитать файл `PROJECT_CONTEXT.md` в корне проекта для понимания глобальной архитектуры.
2. Прочитать все файлы в директории `.agents/rules/` для применения строгих технических ограничений.
3. Взять/проверить задачу в Notion через Notion MCP согласно `.agents/rules/05-notion-tasks.md`, перевести её статус в `In progress` и создать соответствующую Git-ветку.
4. Изучить технологический контекст в `.agents/context/` при необходимости.
5. При выполнении типовых задач (новый эндпоинт, миграция БД) строго следуй алгоритмам из папки `.agents/workflows/`.
